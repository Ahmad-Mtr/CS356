## ✅ GJU-Style MCQs – Lecture 15: **Operating System Security**

---

### **1. What is the main goal of operating system (OS) security?**

A) Improve software performance  
B) Reduce RAM usage  
C) Protect system resources from unauthorized access or modification  
D) Increase hard disk speed

> **Answer:** C) Protect system resources from unauthorized access or modification

---

### **2. Which of the following best describes user authentication?**

A) Mapping between usernames and files  
B) Confirming a user's identity before allowing access  
C) Encrypting stored data  
D) Disabling unauthorized USB devices

> **Answer:** B) Confirming a user's identity before allowing access

---

### **3. What is the main function of an access control mechanism in OS security?**

A) Determine which processes use the GPU  
B) Allocate memory dynamically  
C) Define and enforce policies about who can access which resources  
D) Monitor CPU temperature

> **Answer:** C) Define and enforce policies about who can access which resources

---

### **4. Which of the following is an example of _Discretionary Access Control_ (DAC)?**

A) Access rights are assigned by the OS  
B) Permissions are based on predefined security labels  
C) The owner of a file sets the access rights  
D) Access is granted only to administrators

> **Answer:** C) The owner of a file sets the access rights

---

### **5. In Mandatory Access Control (MAC), access decisions are based on:**

A) User preferences  
B) File size  
C) Security labels and system policy  
D) Application performance

> **Answer:** C) Security labels and system policy

---

### **6. The Bell-LaPadula model focuses on:**

A) Data availability  
B) Data authentication  
C) Data confidentiality  
D) Data integrity

> **Answer:** C) Data confidentiality

---

### **7. Which rule in the Bell-LaPadula model prevents reading data from a higher security level?**

A) _Write Down_  
B) _No Write Up_  
C) _No Read Up_  
D) _No Execute Down_

> **Answer:** C) _No Read Up_

---

### **8. Which model focuses primarily on data integrity instead of confidentiality?**

A) Bell-LaPadula  
B) Biba  
C) RBAC  
D) DAC

> **Answer:** B) Biba

---

### **9. Which Biba rule prevents data from being _written_ to a higher integrity level?**

A) No Read Up  
B) No Write Down  
C) No Read Down  
D) No Write Up

> **Answer:** D) No Write Up

---

### **10. Role-Based Access Control (RBAC) assigns permissions based on:**

A) File type  
B) Username  
C) Job roles within an organization  
D) Encryption level

> **Answer:** C) Job roles within an organization

---

### **11. Which of the following is NOT a typical OS-level protection mechanism?**

A) User authentication  
B) Memory protection  
C) Encryption of email content  
D) Access control lists (ACLs)

> **Answer:** C) Encryption of email content

---

### **12. What is a _rootkit_ in the context of OS security?**

A) A log file used to track user activity  
B) A debugging tool for kernel mode  
C) Malware that hides itself and provides backdoor access  
D) An antivirus software extension

> **Answer:** C) Malware that hides itself and provides backdoor access

---

### **13. What is the difference between a worm and a virus?**

A) Worms are only active on Linux  
B) Worms can self-replicate without a host; viruses need a host  
C) Viruses are encrypted; worms are not  
D) Worms require user interaction; viruses don’t

> **Answer:** B) Worms can self-replicate without a host; viruses need a host

---

### **14. Which component of the OS is primarily responsible for process isolation?**

A) BIOS  
B) File system  
C) Kernel  
D) Terminal

> **Answer:** C) Kernel

---

### **15. What is _sandboxing_ in OS security?**

A) Encrypting applications before running them  
B) Running applications in a restricted environment to limit damage  
C) Deleting system cache  
D) Virtualizing the hard disk

> **Answer:** B) Running applications in a restricted environment to limit damage

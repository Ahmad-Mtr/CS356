## ✅ GJU-Style MCQs – Lecture 13: **Public Key Cryptography & Information Hiding**

---

### **1. What is the key idea behind public key cryptography?**

A) Same key is used for both encryption and decryption  
B) Use of passwords instead of keys  
C) Different keys are used for encryption and decryption  
D) Encrypt the message and the key together

> **Answer:** C) Different keys are used for encryption and decryption

---

### **2. In public key encryption, which key is used to decrypt a message?**

A) Public key of sender  
B) Private key of sender  
C) Public key of recipient  
D) Private key of recipient

> **Answer:** D) Private key of recipient

---

### **3. In digital signatures, what does the sender use to sign a message?**

A) Their private key  
B) Their public key  
C) Receiver’s private key  
D) Symmetric key

> **Answer:** A) Their private key

---

### **4. What does a digital signature provide?**

A) Confidentiality only  
B) Integrity and confidentiality  
C) Integrity and authentication  
D) Encryption

> **Answer:** C) Integrity and authentication

---

### **5. Why can’t symmetric key cryptography provide non-repudiation?**

A) It is too slow  
B) It doesn't support encryption  
C) Both parties share the same key  
D) Keys are always public

> **Answer:** C) Both parties share the same key

---

### **6. In the Diffie-Hellman key exchange, what is exchanged between parties?**

A) Secret key  
B) Private key  
C) Public values derived from private secrets  
D) Digital signature

> **Answer:** C) Public values derived from private secrets

---

### **7. Which of the following is a vulnerability of the basic Diffie-Hellman exchange?**

A) Brute force attack  
B) Birthday attack  
C) Man-in-the-middle attack  
D) Side-channel attack

> **Answer:** C) Man-in-the-middle attack

---

### **8. What does the `SET ROLE` command do in SQL-99 RBAC?**

_(Repeated to reinforce from Lecture 10)_

A) Grants admin privileges  
B) Assigns ownership of a table  
C) Activates a specific role during a session  
D) Encrypts the password for login

> **Answer:** C) Activates a specific role during a session

---

### **9. What is the main purpose of a Certificate Authority (CA) in a Public Key Infrastructure (PKI)?**

A) Encrypt all messages  
B) Manage passwords  
C) Verify identity and bind it to a public key  
D) Generate symmetric keys

> **Answer:** C) Verify identity and bind it to a public key

---

### **10. Which of the following is a trust model used in PKI systems?**

A) Mesh trust  
B) Chain trust  
C) Star trust  
D) Web of trust

> **Answer:** D) Web of trust

---

### **11. Which notation best represents a message that is first signed and then encrypted?**

A) {M}Bob  
B) {[M]Alice}Bob  
C) [{M}Bob]Alice  
D) {[M]Bob}Alice

> **Answer:** B) {[M]Alice}Bob

---

### **12. What is the main goal of steganography?**

A) Encrypt the message  
B) Hide the existence of a message  
C) Break a code  
D) Compress a message

> **Answer:** B) Hide the existence of a message

---

### **13. How does digital watermarking differ from steganography?**

A) Watermarking is visible; steganography is encrypted  
B) Steganography hides messages; watermarking hides ownership or integrity info  
C) Watermarking uses public keys; steganography uses private keys  
D) Steganography is reversible; watermarking is not

> **Answer:** B) Steganography hides messages; watermarking hides ownership or integrity info

---

### **14. Which of the following is a characteristic of a _fragile_ watermark?**

A) Resistant to cropping and compression  
B) It’s visible to the user  
C) It breaks if tampered with  
D) It’s designed for robustness

> **Answer:** C) It breaks if tampered with

---

### **15. In steganography using HTML, how can a message be hidden?**

A) Through metadata headers  
B) Using HTTPS  
C) By embedding bits into RGB color codes or spacing  
D) By encrypting the page title

> **Answer:** C) By embedding bits into RGB color codes or spacing

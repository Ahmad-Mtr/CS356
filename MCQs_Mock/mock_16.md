## ✅ GJU-Style MCQs – Lecture 16: **Network Security**

---

### **1. What is the main goal of network security?**

A) Increase network speed  
B) Prevent unauthorized access and protect data in transit  
C) Improve web browsing performance  
D) Reduce latency

> **Answer:** B) Prevent unauthorized access and protect data in transit

---

### **2. Which of the following is an active attack on network security?**

A) Wiretapping  
B) Traffic analysis  
C) Message modification  
D) Eavesdropping

> **Answer:** C) Message modification

---

### **3. What type of attack involves intercepting and possibly altering communication between two parties?**

A) DoS attack  
B) SQL injection  
C) Man-in-the-middle attack  
D) Replay attack

> **Answer:** C) Man-in-the-middle attack

---

### **4. Which network device filters traffic based on IP addresses and port numbers?**

A) Switch  
B) Firewall  
C) Router  
D) Access Point

> **Answer:** B) Firewall

---

### **5. Which of the following is the BEST description of a firewall?**

A) A device used for email filtering  
B) A system that physically disconnects malicious users  
C) A hardware or software system that enforces access control policies between networks  
D) An encryption tool

> **Answer:** C) A hardware or software system that enforces access control policies between networks

---

### **6. Which of the following firewalls examines the content of the traffic, not just headers?**

A) Packet-filtering firewall  
B) Stateful firewall  
C) Application-layer firewall  
D) Stateless firewall

> **Answer:** C) Application-layer firewall

---

### **7. What is the primary function of an Intrusion Detection System (IDS)?**

A) Stop all malicious activity immediately  
B) Prevent malware from being installed  
C) Monitor network traffic and detect suspicious behavior  
D) Encrypt data in transit

> **Answer:** C) Monitor network traffic and detect suspicious behavior

---

### **8. How does an Intrusion Prevention System (IPS) differ from an IDS?**

A) IPS only logs attacks  
B) IPS actively blocks threats; IDS only detects  
C) IDS is part of the OS; IPS is not  
D) IPS uses antivirus databases

> **Answer:** B) IPS actively blocks threats; IDS only detects

---

### **9. What is a VPN (Virtual Private Network) used for?**

A) Speeding up downloads  
B) Encrypting and securing communication over public networks  
C) Allocating more bandwidth  
D) Controlling local user permissions

> **Answer:** B) Encrypting and securing communication over public networks

---

### **10. Which protocol is commonly used to establish secure communication over VPNs?**

A) FTP  
B) HTTP  
C) IPsec  
D) POP3

> **Answer:** C) IPsec

---

### **11. Which protocol provides confidentiality and integrity at the transport layer?**

A) TCP  
B) TLS  
C) IP  
D) ICMP

> **Answer:** B) TLS (Transport Layer Security)

---

### **12. What kind of attack floods a network with traffic to cause a denial of service?**

A) Man-in-the-middle  
B) DoS  
C) Spoofing  
D) ARP poisoning

> **Answer:** B) DoS

---

### **13. Which of the following is a characteristic of a SYN flood attack?**

A) Exploits ICMP packets  
B) Abuses the TCP three-way handshake  
C) Targets DNS queries  
D) Requires physical access to the network

> **Answer:** B) Abuses the TCP three-way handshake

---

### **14. Which term describes a malicious software that secretly monitors network activity?**

A) Ransomware  
B) Rootkit  
C) Spyware  
D) Worm

> **Answer:** C) Spyware

---

### **15. What is a common defense against ARP spoofing?**

A) IP filtering  
B) MAC randomization  
C) Using static ARP tables  
D) Running antivirus software

> **Answer:** C) Using static ARP tables

## ✅ GJU-Style MCQs – Lecture 17: **Web Security**

---

### **1. What is the goal of web security?**

A) Speed up website rendering  
B) Prevent denial-of-service attacks only  
C) Protect websites and web applications from malicious attacks and data breaches  
D) Improve website SEO rankings

> **Answer:** C) Protect websites and web applications from malicious attacks and data breaches

---

### **2. Which of the following is a common _client-side_ attack in web security?**

A) SQL injection  
B) XSS (Cross-Site Scripting)  
C) Command injection  
D) Directory traversal

> **Answer:** B) XSS (Cross-Site Scripting)

---

### **3. What is Cross-Site Scripting (XSS)?**

A) A method for encrypting browser data  
B) When a user is redirected to another site  
C) Injection of malicious scripts into trusted web content  
D) Rewriting a user’s cookies manually

> **Answer:** C) Injection of malicious scripts into trusted web content

---

### **4. What is the primary risk of XSS?**

A) Slowing down the server  
B) Stealing user session cookies and credentials  
C) Overwriting HTML tags  
D) Replacing a webpage title

> **Answer:** B) Stealing user session cookies and credentials

---

### **5. What is the best defense against XSS attacks?**

A) Changing passwords regularly  
B) Validating input on the server only  
C) Encoding output sent to the browser  
D) Using client-side encryption

> **Answer:** C) Encoding output sent to the browser

---

### **6. What is CSRF (Cross-Site Request Forgery)?**

A) A fake login page  
B) A malware-injected iframe  
C) An attacker tricks a user’s browser into making unintended requests  
D) Stealing cookies through browser extensions

> **Answer:** C) An attacker tricks a user’s browser into making unintended requests

---

### **7. Which of the following is a defense against CSRF?**

A) Use HTTPS  
B) Set `HttpOnly` flag on cookies  
C) Implement anti-CSRF tokens in forms  
D) Disable JavaScript

> **Answer:** C) Implement anti-CSRF tokens in forms

---

### **8. What does the `HttpOnly` flag in cookies prevent?**

A) Man-in-the-middle attacks  
B) Cookies from being accessed via JavaScript  
C) Cookies from being deleted  
D) Secure HTTPS transmission

> **Answer:** B) Cookies from being accessed via JavaScript

---

### **9. What is session hijacking?**

A) A user is logged out suddenly  
B) When a user logs in from a different browser  
C) An attacker gains control over a user’s active session  
D) Resetting a session token

> **Answer:** C) An attacker gains control over a user’s active session

---

### **10. What is a common method to perform session hijacking?**

A) Capturing SSL certificates  
B) Brute-forcing login credentials  
C) Stealing session cookies  
D) DDoS attack

> **Answer:** C) Stealing session cookies

---

### **11. Which web vulnerability allows attackers to inject commands directly into a server-side interpreter (e.g., shell, SQL)?**

A) XSS  
B) CSRF  
C) Injection attack  
D) HTML tampering

> **Answer:** C) Injection attack

---

### **12. Why is input validation important in web security?**

A) To ensure all forms are filled  
B) To protect against server outages  
C) To prevent attacks like SQL injection and XSS  
D) To speed up browser rendering

> **Answer:** C) To prevent attacks like SQL injection and XSS

---

### **13. Which HTTP header helps protect against XSS and clickjacking?**

A) Content-Length  
B) User-Agent  
C) Content-Security-Policy  
D) Accept-Encoding

> **Answer:** C) Content-Security-Policy

---

### **14. Which of the following would best help secure user authentication?**

A) Hiding password fields  
B) Using CAPTCHA  
C) Using multi-factor authentication (MFA)  
D) Redirecting after login

> **Answer:** C) Using multi-factor authentication (MFA)

---

### **15. What is the purpose of using HTTPS instead of HTTP?**

A) Compress traffic  
B) Route through a proxy  
C) Encrypt data in transit  
D) Speed up loading

> **Answer:** C) Encrypt data in transit

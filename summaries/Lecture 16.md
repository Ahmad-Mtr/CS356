## ✅ **Lecture 16: Network Security – Summary (Simplified)**

### 🔐 **What is Network Security?**

- It’s about **protecting data while it travels** between devices over a network (like the internet).
    
- The goal is to **stop unauthorized access**, **prevent data theft**, and **block attacks**.
    

---

### 🚨 **Types of Network Threats:**

1. **Passive Attacks** – Listen and monitor without changing anything
    
    - **Eavesdropping**: Listening to private messages
        
    - **Traffic Analysis**: Observing who talks to whom, when
        
2. **Active Attacks** – Actually change or interrupt communication
    
    - **Modification** of data
        
    - **Denial of Service (DoS)**: Flooding systems to crash them
        
    - **Masquerade**: Pretending to be someone else
        
    - **Replay**: Reusing old messages
        
    - **Man-in-the-Middle**: Intercepting communication
        

---

### 🧱 **Network Protection Methods:**

#### 🔥 **Firewalls:**

- Act like **security guards** for a network.
    
- Block or allow traffic based on rules (like IP address, port, etc.).
    
- Types:
    
    - **Packet-filtering**
        
    - **Stateful inspection**
        
    - **Application-level gateways**
        

#### 👮‍♂️ **Intrusion Detection Systems (IDS):**

- Monitor traffic to **detect suspicious activity**, like someone trying to hack in.
    

#### 🛡 **Intrusion Prevention Systems (IPS):**

- Similar to IDS but can **block** threats in real time.
    

---

### 🌐 **VPNs (Virtual Private Networks):**

- Create a **private, encrypted “tunnel”** for your internet traffic.
    
- Useful for secure remote work or using public Wi-Fi safely.
    

---

### 🔑 **Secure Communication Tools:**

- **IPsec**: Secures network traffic (common in VPNs)
    
- **TLS (Transport Layer Security)**: Protects web communication like when using HTTPS
    

---

### 🧠 Example Highlight:

- Imagine sending a message in a sealed envelope (VPN), guarded by a security camera (IDS), and only the right person can open it (authentication).

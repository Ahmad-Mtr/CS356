## ✅ GJU-Style MCQs – Lecture 11: **Cryptography**

---

### **1. What does Kerckhoffs’ Principle state in cryptography?**

A) The encryption algorithm must always remain secret  
B) Security should rely only on the secrecy of the key  
C) The ciphertext must always be shorter than the plaintext  
D) The algorithm should be changed with every message

> **Answer:** B) Security should rely only on the secrecy of the key

---

### **2. Which of the following is a classical monoalphabetic cipher?**

A) Playfair  
B) Vigenère  
C) Caesar  
D) One-Time Pad

> **Answer:** C) Caesar

---

### **3. In the Caesar cipher, how is encryption achieved?**

A) Shuffling letters randomly  
B) Substituting each letter with one a fixed number of positions ahead  
C) Using a keyword table  
D) Replacing each word with a number

> **Answer:** B) Substituting each letter with one a fixed number of positions ahead

---

### **4. Which technique is most commonly used to break monoalphabetic substitution ciphers?**

A) XOR masking  
B) Frequency analysis  
C) Brute-force hashing  
D) Modular inversion

> **Answer:** B) Frequency analysis

---

### **5. The Vigenère cipher is an example of what type of cipher?**

A) Transposition cipher  
B) Substitution cipher  
C) Polyalphabetic cipher  
D) One-time pad cipher

> **Answer:** C) Polyalphabetic cipher

---

### **6. What is the main difference between Playfair and Caesar ciphers?**

A) Playfair works on words; Caesar on letters  
B) Playfair encrypts pairs of letters; Caesar encrypts one at a time  
C) Playfair uses numbers; Caesar uses ASCII  
D) Playfair uses XOR; Caesar uses hashing

> **Answer:** B) Playfair encrypts pairs of letters; Caesar encrypts one at a time

---

### **7. Why is the One-Time Pad considered unbreakable?**

A) It uses a public key system  
B) The key is repeated multiple times  
C) It uses strong S-boxes  
D) It uses a truly random key as long as the message, used only once

> **Answer:** D) It uses a truly random key as long as the message, used only once

---

### **8. What is the main weakness of the One-Time Pad in practical use?**

A) It's too slow  
B) It's easy to guess the key  
C) Secure key distribution is difficult  
D) It only works on numbers

> **Answer:** C) Secure key distribution is difficult

---

### **9. What does a transposition cipher do?**

A) Replaces each letter with another  
B) Uses XOR to scramble letters  
C) Shuffles the positions of characters without changing them  
D) Adds numbers to letters

> **Answer:** C) Shuffles the positions of characters without changing them

---

### **10. What is a primary limitation of the Caesar cipher?**

A) It uses too much memory  
B) It only supports lowercase letters  
C) It has very few key possibilities  
D) It requires a shared key

> **Answer:** C) It has very few key possibilities (only 25 shifts)

---

### **11. What cryptanalysis method was used to break the Zimmerman Telegram?**

A) Differential cryptanalysis  
B) Frequency analysis and codebook decryption  
C) Polynomial factorization  
D) Modular exponentiation

> **Answer:** B) Frequency analysis and codebook decryption

---

### **12. In the One-Time Pad, if the key is reused, what kind of attack becomes possible?**

A) Brute force  
B) Linear cryptanalysis  
C) Known plaintext attack  
D) Birthday attack

> **Answer:** C) Known plaintext attack

---

### **13. In classical ciphers, what are “S-boxes” used for?**

A) Substituting key bytes  
B) Confusing the relationship between input and output  
C) Calculating CRC checks  
D) Key expansion

> **Answer:** B) Confusing the relationship between input and output

---

### **14. Who is credited with formalizing the idea of "confusion and diffusion" in cryptography?**

A) Alan Turing  
B) Bruce Schneier  
C) Claude Shannon  
D) Ron Rivest

> **Answer:** C) Claude Shannon

---

### **15. What best describes the difference between a code and a cipher?**

A) Codes work on characters, ciphers on words  
B) Codes replace meanings; ciphers operate on characters  
C) Codes use algorithms, ciphers use lookups  
D) Codes are faster to break than ciphers

> **Answer:** B) Codes replace meanings; ciphers operate on characters
